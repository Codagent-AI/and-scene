# and-scene

And Scene is a project for building a presentation-generation agent skill.

The intended presentation model is not a stack of unrelated slides. It is one
diagrammatic scene that evolves through named steps: elements appear, move,
collapse, connect, and re-label as the talk arc develops.

## Development

```bash
npm ci
npm test                  # fast unit and contract tests (Vitest)
npm run test:integration  # bootstrap materialization and screenshot helper (installs, Chromium)
npm run test:e2e          # production verification of the reference presentation and its failure contract
npm run lint
npm run build
npm run verify            # build + render every registered presentation in Chromium on 127.0.0.1
npm run inspect -- how-to-make-a-presentation   # settled per-step screenshots + advisory warnings
npm run sync:templates    # refresh skills/presentation/templates/bootstrap from the canonical sources
```

## Layout

- `src/presentation-kit/`: the reusable, style-neutral scene kit (canonical source).
- `src/presentations/`: the presentation registry and the committed sample,
  "How to Use This Skill to Make a Presentation" (`/how-to-make-a-presentation`).
- `skills/presentation/`: the agent skill (`SKILL.md`), its helper scripts, and the scaffold templates.
  `templates/bootstrap/` is generated by `npm run sync:templates`; keep it in sync with the kit and scripts.
- `scripts/verify.mjs`, `scripts/inspect-presentation.mjs`: browser verification and inspection.
