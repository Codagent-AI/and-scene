Checks below apply those rulings within the approved definition.

Checks use automated tests, commands, or file inspection. Procedural skill requirements are checked in the distributed instructions/templates rather than by running an agent through the workflow. Screenshot files may be inspected after scripted capture; advisory diagnostics alone are not proof of visual quality. Only the test plan's named integration and end-to-end cases are planned. This merge does not assert implementation or verification completion.
