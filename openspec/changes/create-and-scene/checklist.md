Source is `lead`, `implementor`, `both`, or `crosscheck` for coverage added from the approved definition. No implementation or verification result is claimed here.

Checks include those rulings' concrete thresholds and hooks where applicable. Only INT-001, INT-002, E2E-001, and E2E-002 from `test-plan.md` are planned as integration or end-to-end tests. Skill procedure checks inspect instructions/templates rather than executing an agent journey. Screenshot diagnostics are advisory and do not establish visual quality by themselves.
