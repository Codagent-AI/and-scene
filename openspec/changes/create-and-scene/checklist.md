# Verification Checklist: create-and-scene

| ID | Behavior | Spec reference | How to verify |

| I-1 | A step has stable id, era label, presenter title, browse caption, and diagram state; the type contract enforces them | evolving-scene-presentations, "Scene step model" / "Step carries narration and identity" | Type-level and unit contract test over `types.ts` and the sample steps; `npm run build` type check |

| I-4 | A persisting entity keeps a stable `layoutId` and morphs in place across consecutive steps | evolving-scene-presentations, "Persisting entity morphs" | Component test: same layoutId element is retained across a step change; inspect sample `entities.ts` and steps reuse ids |
