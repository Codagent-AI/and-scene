# Verification checklist: create-and-scene

Spec paths are relative to `openspec/changes/create-and-scene/`. "Unit test" means a fast Vitest test run by `npm test`. INT-001, INT-002, E2E-001, and E2E-002 are the test plan's integration and end-to-end tests, run by the separate browser-backed npm script.

| ID | Behavior | Spec reference | How to verify |

| I-2 | On-screen step numbers derive from position, so insert, remove, or reorder needs no renumbering | same, "Order-derived numbering" | Unit test: reorder a steps array and assert the derived numbers |
