# Verification Checklist: create-and-scene

Check names: **Unit** = Vitest via `npm test`; **Inspect** = read code/files; **Lint/Build** = `npm run lint`, `npm run build`;
**INT-001/INT-002** = integration tests; **E2E-001/E2E-002** = end-to-end tests (all named in the test plan; run via the separate browser-backed npm script, not `npm test`).
