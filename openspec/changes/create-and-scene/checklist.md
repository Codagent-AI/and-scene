# Merged behavior verification checklist

This is a verification plan, not a record of passed checks. IDs retain the lead (`L-`) and implementor (`I-`) provenance; combined IDs cover the same behavior with the stronger checks below. `X-` rows are definition crosschecks missing from both inputs. Source describes behavior coverage, not who proposed a particular test.

Unit, type-contract, and component tests run in the fast `npm test` suite unless a build is explicitly required. Integration tests are limited to INT-001 and INT-002 (`npm run test:integration`); end-to-end tests are limited to E2E-001 (`npm run verify`) and E2E-002 (`npm run test:e2e`). Inspection means reading the named implementation or procedure and recording concrete findings against each stated condition. Procedure inspection checks the actual branches and ordering, rather than accepting keyword presence as proof. Browser actions below belong to those automated named tests; visual-review requirements are audited by inspecting the skill procedure.
