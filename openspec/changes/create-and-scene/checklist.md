# Checklist: create-and-scene

Merged from lead L-1–L-75 and implementor I-1–I-39 against the proposal, design, canonical specs, and test plan. Every original ID is retained below; an ID repeated across rows means its compound behavior was split into separate checks. Source describes checklist provenance; `crosscheck` identifies obligations found in the definition that neither checklist explicitly covered.

These are planned checks, not evidence of execution. Unit and contract checks run under fast Vitest `npm test`; type fixtures also use TypeScript. INT/E2E/browser checks run in a separate npm script, including INT-001, INT-002, E2E-001, and E2E-002. `npm run verify` is the production browser gate. Required AT-001–AT-004 follow the public skill in disposable projects using `chrome-devtools-axi` (AXI), starting with a structure snapshot and then settled screenshots. Static skill checks do not substitute for required AT journeys. Record any unexecuted check as `not verified` when evidence is added. The repository has no hosted CI: do not add CI configuration to implement the test plan's “every pull request” execution wording (AGENTS.md takes precedence).

AT-003 sample evidence points to the fixture for departures when not applicable to the sample. This preserves the required kit behaviors without changing the canonical nine-step outline.
