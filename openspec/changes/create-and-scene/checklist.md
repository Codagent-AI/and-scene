# Verification Checklist: create-and-scene

This is a merged verification plan, not completed verification evidence. IDs retain lead (`L-`) and implementor (`I-`) provenance; `C-` rows cover requirements missed by both. Source identifies the originating checklist(s), or `crosscheck` for added coverage. Original behaviors are retained, overlapping rows combined, and checks strengthened where necessary. An original ID can recur when its row bundled independent behaviors now checked separately.

References are relative to `openspec/changes/create-and-scene/`: **Scene** = `specs/evolving-scene-presentations/spec.md`; **Skill** = `specs/presentation-skill/spec.md`; **Verification** = `specs/presentation-verification/spec.md`. Kit/component/contract tests are fast Vitest tests under `npm test`; type fixtures are compiled by TypeScript. **SKILL inspection** means reading `skills/presentation/SKILL.md` and templates for the specified procedure, ordering, and exceptions, rather than merely matching headings. Browser-backed and subprocess checks are limited to the named `INT-001`, `INT-002`, `E2E-001`, and `E2E-002` tests in `test-plan.md`, run separately from `npm test`. Component event synthesis below is automated testing. Visual-quality inspections below inspect source, geometry, and instructions; screenshots and advisory diagnostics alone do not establish a passing visual-composition verdict.
