# create-and-scene verification checklist

Merged from the definition-only lead checklist (L-1–L-70) and implementor checklist (I-1–I-44). The ID column retains every contributing ID; an ID can occur in several rows when its original row bundled different behaviors. Source describes checklist provenance, not verification status. C-* rows cover definition behaviors neither original checklist explicitly checked.

References: ESP = specs/evolving-scene-presentations/spec.md; PS = specs/presentation-skill/spec.md; PV = specs/presentation-verification/spec.md. All paths are repository-relative unless stated otherwise. Repository requirements are in AGENTS.md (called CLAUDE.md in the original checklists).

These are planned checks, not claims of executed verification. Unit, component, type-contract, and file-contract tests run under npm test unless a build check is specified. Inspection means reading source, configuration, or the skill procedure; it never means an agent operating the product. Browser-backed integration and end-to-end coverage is restricted to INT-001, INT-002, E2E-001, and E2E-002 from test-plan.md. No acceptance journeys are run or cited as checklist checks.
