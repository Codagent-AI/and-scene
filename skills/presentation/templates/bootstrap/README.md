# Presentations

Scaffolded by the `presentation` skill: Vite + React + TypeScript, the vendored scene
kit in `src/presentation-kit/`, and the registry in `src/presentations/index.ts`.

- `npm run dev` / `npm run build` / `npm run lint`
- `npm run verify` builds, then renders every registered presentation step by step
- `npm run inspect -- <slug>` captures settled screenshots and prints advisory warnings
