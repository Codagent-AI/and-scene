# New presentation templates

Copy this folder's files into `src/presentations/<slug>/` (renaming `Talk.tsx`, `entities.ts`,
`talk.css`, and `steps/`), replace every `{{placeholder}}`, add one step file per step, then
apply `registry-line.txt` and `verification-entry.json` to the host project.
These files are intentionally not compilable until the placeholders are filled in.
