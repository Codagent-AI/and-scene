# Reference presentation

Created using the local presentation skill procedure and the approved, complete
nine-beat outline. No gathering questions were needed: the OpenSpec supplied the
topic, each title/caption and the scene intent. This reference uses a warm paper,
forest ink and vermilion visual direction, with all styling in presentation.css.

The conversation, tray and cards accumulate in one grouped SampleScene. Stable
IDs and literal coordinates keep previous entities in place. Later beats add the
kit socket, verification, edit loop and outer reveal. Metadata is independently
checked against scripts/reference.mjs by unit and production verification tests.

Functional verification is automated. Independent acceptance reviews visual
composition and the future skill's conversational workflow.
